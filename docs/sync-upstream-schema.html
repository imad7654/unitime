Overview

sync-upstream.sh keeps DigiPen's forked UniTime repository synchronized with the official upstream (github.com/UniTime/unitime). It detects new upstream commits, archives the current build, merges changes, rebuilds the WAR artifact, and optionally redeploys to a local Docker environment.

Safety guarantees: the script aborts cleanly on merge conflicts, preserves the old version in a dated archive, and never leaves the repository in a dirty state.
